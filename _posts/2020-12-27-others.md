Over my programming life I've written a lot of code. Here I'd like to describe some extra repos on my GitHub that aren't covered by the other posts.

The repos are:
  - [Explore and Analysis](https://github.com/salomaoalves/DataScience_Analysis-Explore): a bunch of Python code testing methods and aggregations to explore and analyze some data.
  - [Machine Learning Python](https://github.com/salomaoalves/DataScience_MachineLearning): examples of simple ML problems (Customer Churn/Satisfaction, Energy Prediction, Fraud Detection) using Python, all proposed by *Data Science Academy*.
  - [Machine Learning Octave](https://github.com/salomaoalves/MachineLearning): an example of the Linear and Logistic Regression algorithms using Octave.
  - [Projects Fields](https://github.com/salomaoalves/DataScience_Others): projects from some areas of Data Science: marketing analytics and recommender systems.
  - [Tableau Dashboards](https://github.com/salomaoalves/TableauDashboards): some Tableau files with examples of dashboards. They're a little old; I made them for a course I took on Udemy, for learning purposes.
  - [TensorFlow](https://github.com/salomaoalves/TensorFlow): a simple Linear Regression using the Python library TensorFlow, just a code example.
  - [Python Things](https://github.com/salomaoalves/PythonThings): a bunch of Python code: some exercises, random programs and some code related to a few Python libraries.
  - [College Assignment](https://github.com/salomaoalves/College-Assignment): all the assignments I did during college, some of them in groups with colleagues.
